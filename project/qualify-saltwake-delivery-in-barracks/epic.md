# Qualify Saltwake delivery in Barracks

## Summary

Implement and rehearse a simpler project delivery workflow with source and tracker separation, supervised Rust jobs, explicit ownership, exact-build acceptance and controlled integration. Preserve live Saltwake work until a separately authorized whole-team cutover.

## Goals

- Deliver a simpler scoped implementation/review/integration workflow with project-specific acceptance.
- Demonstrate actual Rust execution and disposable whole-team recovery before proposing transfer.

## Non-Goals

- Live Saltwake source, assignment, tracker or deployment changes before final transfer authorization.
- Reproducing every historical Saltwake ceremony or resuming the separately deferred SQLite Library migration.

## Success Measures

- The complete disposable rehearsal and fault matrix pass with truthful evidence states and one project write authority.
