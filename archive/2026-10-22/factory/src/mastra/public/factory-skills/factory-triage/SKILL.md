# Barracks triage

Load `barracks-team` and `barracks-ba`. Confirm the target repository and canonical ticket, then inspect full source context, dependencies and current behavior.

Write an evidence-backed understanding, acceptance criteria, exclusions and readiness verdict to the owning story and session. If product scope is unsettled, report the exact blocker and recommended question to the Lead and finish the pass without advancing uncertain work.

When readiness is established, use Factory's current phase signal and governed transition tool to request the next declared phase. Read the current revision and available transition contract; use only actual IDs and allowed moves. Keep source-system comments and status changes within explicit user authorization.
